# Frontend What2Watch

Ce dossier contient l'interface React de l'application.

## Commandes utiles

```bash
cd frontend
npm install
cp .env.example .env
npm run dev
```

Application :
- `http://localhost:5173`

API attendue :
- `http://localhost:8000/api`

Pour une vue d'ensemble du projet, voir le `README.md` a la racine.
